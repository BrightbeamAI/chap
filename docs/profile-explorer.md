# What each profile unlocks

Generated by `packages/create-chap-app/scripts/build-explorer.mjs` from the
templates' `diff-profiles` workload. Each table runs the same calls with
one profile added to the set and without it, and shows the rows that
change. The TypeScript and Python templates answer every row the same way,
which the build checks. The decisions in the workload are scripted; in a
generated project the decision is made in the desk.

A method a profile owns is refused with `-32601` on a workspace that does
not advertise the profile. The mode ceiling is enforced on every workspace;
`modes/1.0` adds the rule that a trial-mode task requires review.
